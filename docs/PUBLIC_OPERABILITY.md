# Public operability and limitations

## Correction and support

Use the public GitHub issue form for product, accessibility, broken-link, or possible data-evidence reports. It requires GitHub sign-in; this pilot therefore does **not** meet any future no-account correction-intake gate. Do not submit personal, location, payment, or sensitive data.

For authoritative source correction, contact the original publishers through the linked [Tainan licensed-market dataset](https://data.gov.tw/dataset/53634) or [Tainan district-code dataset](https://data.tainan.gov.tw/DataSet/Detail/70d961d2-9f38-4112-847d-907b436820ab). The product does not promise an SLA or an outcome for a report.

## Privacy

This static site has no account system, analytics, advertising, location collection, runtime database, or runtime credential. It does not scrape Google Places. Maps is opened only after a visitor activates a public name-and-permitted-area search link. GitHub receives information only if a visitor voluntarily opens/submits a GitHub issue.

## Accessibility

The public product provides semantic landmarks, a skip link, keyboard-operable native controls, visible focus, labelled date/filter/search controls, status announcements, contrast-aware text/icon states, and reduced-motion support. Report a barrier through the issue form with browser/device details if possible.

## Known limitations

Coverage is the reviewed Tainan licensed-market register only. The product reports normal weekly schedule evidence, not live opening, temporary closure, weather, festival, stall, exact hours, distance, or coordinates. Source update timestamps can be unavailable. Maps results are not official coordinates. This is a public pilot, not public beta.
